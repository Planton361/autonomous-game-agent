## Outcome

- The relay reads only the supplied newline-terminated response file, validates its M-021 envelope,
  and reuses M-021 correlation before it opens the feed.
- It serializes the unchanged raw payload as one UTF-8 JSONL object, appends it once, flushes, and
  fsyncs before returning immutable relay metadata.
- Missing, incomplete, non-UTF-8, invalid, malformed, or mismatched responses leave an existing
  feed byte-for-byte unchanged. The response file remains unmodified.
- Non-standard JSON constants (`NaN`, `Infinity`, and `-Infinity`) are rejected before response
  correlation or feed access; serialization also forbids non-finite output values.

  screenshot evidence, create evidence/log records, create parent directories, poll, or access a
  network/input/runtime boundary.
