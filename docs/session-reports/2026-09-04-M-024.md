## Outcome

  appends one evidence event containing the exact serialized `EvidenceRecord` metadata.

  the returned request binds exactly to the saved evidence ID.
- Existing request targets reject before capture where possible. A later M-018 publication failure
  leaves durable screenshot evidence and its append-only event intact.
