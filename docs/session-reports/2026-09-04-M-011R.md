## Root Cause

`TaskSpec.target` already uses the typed `GroundedTarget` union. `TaskCompletionEvent.target` instead used the scalar-only `JsonObject` contract, while completion conversion serialized targets containing nested `evidence_ids` and `screen_position` values. A real `VisibleObjectTarget` verifier-terminal completion therefore raised a Pydantic `ValidationError` before an event could be emitted.

## Implemented

- Replaced the completion-event target field with the existing typed `GroundedTarget` union.
- Preserved the exact `TaskSpec.target` when converting a `TaskCompletion` into an event.
- Kept `TaskSpec.JsonObject` scalar-only.
- Added target-specific SQLite serialization and JSON-mode typed target restoration, preserving the existing discriminator and strict tuple target fields.
- Added `VisibleObjectTarget`, `VisibleScreenPointTarget`, targetless, verifier-terminal, event JSON, and SQLite round-trip coverage.
