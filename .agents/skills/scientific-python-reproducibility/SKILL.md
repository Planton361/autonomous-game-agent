# Scientific Python reproducibility

Use uv and the committed lockfile. Record run mode, provenance, seed, config identity, and commit identity for experiments. Do not admit contaminated data into eligible training; freeze model and Body versions within each run.

Do not begin RL work before detector targets are valid. Distinguish code correctness from detector uncertainty and scientific interpretation. Preserve no-spoiler evidence rules, run-mode separation, and provenance rather than treating a passing test as scientific evidence.
